How do I create effective prompts for ChatGPT to get better code?

AI & ChatGPT 👤 Musa Sani 🕐 Started 2 hours ago 👁️ 342 views
MS
Musa Sani OP 2 hours ago

Assalamu alaikum everyone! I've been trying to get ChatGPT to help me write JavaScript functions, but the results are often generic or not exactly what I need.

For example, when I ask "write a function to sort an array", it gives basic code but doesn't handle edge cases. What techniques can I use to get better, more specific results?

Any tips from the instructors would be appreciated! 🙏

AB
Ahmad Bello Instructor ✓ Accepted Answer 1 hour ago

Great question Musa! Here are my top tips for effective code prompting:

1. Be specific about context:

Instead of "write a sort function", try: "Write a JavaScript function that sorts an array of objects by a 'date' property in descending order, handling null values gracefully."

2. Provide examples:

Show ChatGPT an example of your input data and expected output.

3. Specify constraints:

Mention performance requirements, browser compatibility, or coding style preferences.

4. Iterate:

Don't expect perfection on the first try. Ask "now add error handling" or "optimize this for large datasets".

We cover all of these techniques in Module 2 of the AI course! 📚

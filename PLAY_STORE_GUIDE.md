## STEP 1: Install Prerequisites (One-time, ~30 mins)

1. **Node.js** (v18+) — https://nodejs.org
2. **Android Studio** — https://developer.android.com/studio
3. **Java JDK 17** (bundled with Android Studio)
4. **Google Play Developer Account** — $25 one-time at https://play.google.com/console

Verify installations:
```bash
node --version    # v18+
java --version    # 17+
```

---

## STEP 2: Create Release Keystore (⚠️ CRITICAL — BACK THIS UP!)

The keystore signs your app. **Losing it = you can NEVER update your app again.**

```bash
keytool -genkey -v \
  -keystore kboa-release.keystore \
  -alias kboa \
  -keyalg RSA -keysize 2048 \
  -validity 10000
```

- Store password: choose STRONG password
- Save these 4 things in a password manager:
  - keystore file (`kboa-release.keystore`)
  - alias (`kboa`)
  - store password
  - key password

Copy the file to `android/keystore.properties` from the template.

---

## STEP 3: Install Capacitor & Build the Android Project

From the `kboa-academy` folder:

```bash
# Install dependencies
npm install

# Add Android platform
npx cap add android

# Sync web code → Android project
npx cap sync android

# Open in Android Studio
npx cap open android
```

---

## STEP 4: Firebase Setup for the App

1. Go to [Firebase Console](https://console.firebase.google.com) → Your project
2. **Project Settings → Add App → Android icon**
   - Package name: `ng.edu.kboa.app`
   - App nickname: KBOA Academy
3. Download `google-services.json`
4. Place it at: `android/app/google-services.json`
5. In Firebase Console → **Cloud Messaging** → copy your **Server Key** (needed for sending pushes from your backend)

## STEP 6: Test on a Real Device

```bash
# Enable USB debugging on your Android phone (Settings → Developer Options)
# Connect via USB, then:

npx cap run android
```

**Test checklist:**
- [ ] App opens to login page
- [ ] Login/logout works
- [ ] Video plays in course learning
- [ ] Back button navigates correctly (doesn't exit accidentally)
- [ ] Rotate screen — layout adjusts
- [ ] Offline banner appears when airplane mode ON
- [ ] Push notification token registers (check logcat)

---

## STEP 7: Build Release APK/AAB

```bash
# Generate the App Bundle (what Play Store requires)
npx cap sync android
cd android
./gradlew bundleRelease
cd ..

# Output file:
# android/app/build/outputs/bundle/release/app-release.aab
```

Also build an APK for internal testing:
```bash
cd android && ./gradlew assembleRelease
# Output: android/app/build/outputs/apk/release/app-release.apk
```

| Asset | Size | Notes |
|-------|------|-------|

| Feature graphic | 1024×500 PNG | Key visual with app name |

### Content Rating Questionnaire
- Category: **Educational**
- No user-generated content concerns → answer accordingly
- Target audience: **18+** (or 13+ with parental guidance)

### Data Safety Section (Required!)
Declare what data the app collects:
- ✅ Email address — collected, used for account
- ✅ Phone number — collected, optional
- ❌ Not shared with third parties
- ✅ Data encrypted in transit (Firebase SSL)
- ✅ Users can request data deletion

## STEP 9: Release

1. Play Console → **Create app**
2. Set up → **Production** (or start with **Internal testing** first!)
3. Upload your `.aab` file
4. Complete all checklist items (content rating, data safety, etc.)
5. **Internal testing track first** — add your own email as tester
6. Test the download from Play Store on your device
7. Promote to **Closed testing** → then **Production**

### Recommended Release Strategy
```
Internal testing (you + team) → 2-3 days
    ↓
Closed testing (20-50 real students) → 1-2 weeks
    ↓
Production (everyone) 🚀
```

## STEP 10: Sending Push Notifications

From your Firebase project or a Cloud Function:

```javascript
// Example: Notify students of new lesson (Cloud Function)
const message = {
  notification: {
    title: '📚 New Lesson Available!',
    body: 'Module 3: Advanced Prompting is now live in AI & ChatGPT Mastery'
  },
  data: {
    type: 'new_lesson',
    courseId: 'ai-chatgpt-mastery'
  },
  tokens: ['fcm_token_1', 'fcm_token_2'] // from Firestore users collection
};

await admin.messaging().sendMulticast(message);
```

## 🚨 Common Issues & Fixes

| Problem | Fix |
|---------|-----|
| `google-services.json not found` | Put it in `android/app/` folder, not project root |
| App shows white screen | Run `npx cap sync android` again; check console errors |
| Push notifications not working | Check FCM server key; test with Firebase "Notification composer" |
| Keystore lost | ❌ Irrecoverable — that's why we made TWO backups |
| App rejected for "WebView wrapper" | Add native features: push notifications, offline mode, share (we have all ✓) |
